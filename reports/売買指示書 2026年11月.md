# 売買指示書(2026年11月5日版)

**対象:** 資金10万円未満、短期売買、許容損失 −20%、証券口座あり(FX口座なし)
**作成方法:** 学習ガイドの調査に加え、米セントルイス連銀(FRED)の実際の日次データで次を自分で検証した。
- ドル円:1971年〜2026年10月30日
- 日経平均:1949年〜2026年11月5日

> **最初に正直に言っておくこと**
> - 検証した売買ルールのうち、**どの時代でも安定して勝てたものは1つもない**。下の指示は「過去に有利だった条件で、負けを小さく抑えて参加する」ためのもの。利益の保証はない。
> - 使ったデータの最終日は、ドル円が10/30、日経平均が11/5。**注文の前に、必ず今の値段を自分で確認すること。**
> - 投資判断と損益は自己責任。

## 0. 全体ルール(これを破ったら指示は無効)

| ルール | 中身 |
|---|---|
| **口座全体の撤退ライン** | 入金額から −20%(10万円なら残高8万円)で**全取引を停止**し、デモ口座に戻る |
| **1回の取引で失ってよい額** | 資金の2%まで(10万円なら**2,000円**)。注文と同時に損切り注文(逆指値)を必ず入れる |
| **取引の単位** | FXは**1,000通貨以下**。1万通貨は禁止 |
| **実効レバレッジ** | 3倍以下(ドル円1,000通貨なら約1.6倍) |
| **重要発表の前後** | 下の「イベント表」の日は、新しく建てない |
| **売り(ショート)** | ドル円の売りは禁止(理由は2章) |
| **金曜の夜** | 新しく建てない(週末の窓開けリスク) |
| **年末年始(12/26〜1/4)** | ポジションを持たない(取引が薄く急変しやすい。2019/1/3の急変はこの時期) |

## 1. まずやること(今週)

1. **国内FX口座を開く。** 少ない単位で取引できる会社を選ぶ(1通貨や1,000通貨から取引できる会社がある。最小単位は各社の公式サイトで確認すること)。**海外FX業者は使わない。** 金融庁の無登録業者警告リストには1,158件(国内721件・海外437件、2026年10月23日更新)が載っている([金融庁](https://www.fsa.go.jp/ordinary/chuui/mutouroku.html))。
2. 口座ができたら、**最初の2週間はデモ口座か100通貨〜1,000通貨**で、下の手順を練習する。
3. **取引日誌**をつける。記録するのは次の4つ。
   - 入った理由
   - 損切りの位置
   - 結果
   - 守れなかったルール

## 2. ドル円の指示:**「下がったら買う」だけをやる**

### 検証で分かったこと(2003〜2026年、金利差によるスワップ込み、往復2銭のコスト込み)

| やり方 | 2003〜2014年 | 2015〜2026年 | 判定 |
|---|---|---|---|
| ずっと買い持ち | 年+1.3% | 年+4.3% | スワップ(金利差)が支え |
| 移動平均・MACD・ブレイクアウトで売買両方 | ほぼ0〜マイナス | ほぼ0〜マイナス | **使えない** |
| 売り(ショート)を含む戦略 | 大半がマイナス | 大半がマイナス | 売るとスワップを払うので不利 |
| **ボリンジャー下限(−1.5σ)で買い→20日線で利確(買いのみ)** | 年+0.4%、勝率65% | **年+2.5%、勝率79%** | 最近の相場では有効。古い時代は弱い |
| 同上+200日線が横ばいの時だけ | 年0.0% | **年+2.7%、勝率81%、最大下落−9.9%** | 今のようなもみ合い相場向き |
| RSI(2)の押し目買い | 年+1.0% | 年+0.3% | 弱い |

(年率は「レバレッジ1倍」で計算した値。1,000通貨・資金10万円なら、損益はこの約1.6倍になる)

### 今の状況(10/30終値157.47、11/5は報道ベースで約158.3)

- 直近1か月は**156.9〜158.8円の狭い範囲**でもみ合っている。200日線(158.5)はほぼ横ばいで、トレンドはない。
- **上がりにくい理由:** 2026年は、財務省が4〜5月に11.7兆円、7月30日〜8月26日に15.4兆円の円買い介入をした。米国東部時間7/31には日米協調介入もあった。8/27〜10/28は介入なし([財務省](https://www.mof.go.jp/policy/international_policy/reference/feio/index.html))。160円台は介入を警戒するゾーン。

#### 検証:過去の円買い介入の直前の水準と、その後の下落(財務省の日次データ+FREDのNY正午レート)

| 介入開始 | 直前のレート | 翌日 | 5日後 | 60日以内の最大下落 |
|---|---|---|---|---|
| 2022/9/22 | 144.1円 | −1.0円 | +0.3円 | −9.3円 |
| 2024/4/29 | 157.6円(日中は160円台) | −0.1円 | −3.8円 | −4.8円 |
| 2024/7/11 | 161.7円 | −3.9円 | −4.8円 | **−21.1円** |
| 2026/4/30 | 160.2円 | −3.5円 | −3.8円 | −3.8円 |
| 2026/7/30 | 163.9円 | **−4.4円** | −6.9円(8/3時点) | — |

- ここ2年の介入は、すべて**157.6〜163.9円**で始まった。1日で3〜4円下落したケースが多い。
- 1,000通貨の買いを持っていると、**介入1回で約4,000円**の損失になる。これは「1回2,000円まで」のルールの2倍。だから**160円を超えたら持たない**。
- 2026/7/30の回は、財務省の日次内訳が11/9に公表される予定。表の数字は、為替レートの動きから読み取ったもの。
- **下がりにくい理由:** 日米の金利差(FF金利3.88%、日本の3か月金利は約1.56%)があり、買いならスワップをもらえる。FRBの誘導目標は3.75〜4.00%で、10/28は2人が利上げを主張して反対した([FRB](https://www.federalreserve.gov/newsevents/pressreleases/monetary20261028a.htm))。12月の利上げはほぼ織り込まれている(約85%、報道ベース)。
- **下がるリスク:** 日銀が12月か1月に利上げする可能性が高い。12/18の会合で円が急に買われるかもしれない。

### 具体的な指示

| 項目 | 指示 |
|---|---|
| **方向** | 買いのみ |
| **買う条件** | 終値が**20日ボリンジャーの−1.5σ以下**(今の水準で**約157.2円以下**)。目安は**156.5〜157.2円**。159円以上では買わない |
| **数量** | 1,000通貨(必要な証拠金は約6,300円) |
| **損切り** | **155.0円**に逆指値(1,000通貨なら損失は約1,500〜2,200円) |
| **利確** | **20日線(今は約158.0円)に戻ったら半分、158.8円で残り** |
| **160円を超えたら** | 持っているなら**すべて決済**する。介入で一瞬に4〜5円落ちたことがある |
| **保有中止の日** | 12/17〜18(日銀会合)の前日までに決済しておく |
| **155円を割ったら** | もみ合いが終わった合図。**しばらく買わない**(次の日銀会合が終わるまで様子見) |

## 3. 日経平均の指示:**今は「見るだけ」、練習はデモで**

### 検証で分かったこと

- **今の形**は、4日続落、RSI(2)=4(極端な売られすぎ)、上向きの200日線(61,937)のわずか1.4%下、高値72,366から−15.6%。
- この形のあとの値動きは、時代によって**正反対**だった。

| 時代 | 5日後に上がった確率 | 5日後の平均 | 20日後の平均 |
|---|---|---|---|
| 2008〜2026年(上昇相場) | **77%** | +1.1% | +2.5% |
| 1990〜2007年(長期下落相場) | 30% | −0.7% | −2.3% |

つまり「上昇相場が続いているなら反発しやすい」が、「相場の流れが変わる途中なら、まだ下がる」。どちらかは事前には分からない。

- **押し目買いの弱点:** RSI(2)の押し目買いは勝率70%台と高い。しかし勝ちの平均が負けの平均の0.5〜0.65倍しかない。**小さく勝って、たまに大きく負ける**。損切りなしだと、1回で−24%の負けがあった。
- **ハロウィーン効果**(11〜4月が強い)は、日経では2つの時代とも確認できた(2008〜2026年は11〜4月が年率+14.8%、5〜10月が+6.3%)。曜日効果や月末月初効果は、時代によって逆転しているので**使えない**。

### 具体的な指示

- 資金10万円未満では、日経平均の短期売買は**適正な数量にできない**。日経225の先物やCFDは最小単位でも数十万円分の取引になり、1日に約1,000円(1.6%)動く。そのため、損切りを2,000円以内に収められない。
- そこで、日経は**デモ口座で次のルールを練習**する。

| 項目 | 練習ルール |
|---|---|
| 買う条件 | RSI(2)が10未満、かつ**終値が200日線より上** |
| 利確 | 終値が5日線を上回ったら |
| 損切り | 買値から−4% |
| 今週 | **終値が200日線(約61,900)を上回るまで買わない**。上回らずに59,600(ボリンジャー−2σ)を割るなら、下落相場入りを疑う |

- 現物でやりたい場合は、日経平均連動ETFを**単元未満株で1万円以内**にとどめる(証券会社が単元未満株での取引に対応しているか確認すること)。

## 5. 毎回の手順(チェックリスト)

1. 今日はイベント表の日ではないか?
2. 口座の残高は撤退ライン(−20%)より上か?
3. 買う条件をすべて満たしているか?(「なんとなく安い」は不可)
4. 損切り価格 × 数量 = 損失額が2,000円以内か?
5. **注文と同時に逆指値を入れたか?**
6. 決済したら日誌に書いたか?

**負けたあとに取り返そうとして数量を増やすのは、最も多い破産パターン。** 調査では、ブラジルで300日以上デイトレードした人の97%が損をし、台湾のデイトレーダーで手数料を引いて予測可能な形で勝っていた人は1%未満だった。勝つ人は「上手い人」というより「ルールを守って小さく負ける人」。

## 付録:検証の方法

- **データ:** FRED(DEXJPUS:ドル円のNY正午レート、NIKKEI225、DFF:FF金利、IR3TIB01JPM156N:日本の3か月金利)
- **ドル円:** 金利差を日割りで足した(買いは受け取り、売りは支払い)。コストは片道1銭。
- **日経平均:** 片道0.05%。配当は含まない。
- **時代を2つに分けた理由:** 片方の時代だけでうまくいくルールは、たまたま当てはまっただけの可能性が高い。両方の時代で比べ、時代をまたいでも通用するかを確かめるため。
- **データの限界:** 日次の終値データなので、仲値(9:55)などの日中のクセは検証できていない。
